# Choo Xiao Ying — Portfolio

A static site (plain HTML/CSS/JS, no build step), hosted on vercel and details submitted to Google Search Console and Bing Webmaster. Open `index.html` in a browser to view it. Helping my sister make a website for her since she's doing media production; go hire her, her work's pretty interesting and I had fun making her website.  

## Files
- `index.html` — page layout and copy
- `projects.js` — the filmography list; edit this to add, remove or reorder projects
- `styles.css` / `script.js` — look and behaviour
- `assets/stills/` — web-sized stills used on the site (originals live in `pictures/`, which isn't uploaded)
- `assets/img/` — portrait photos

Her home address and phone number from the CV are intentionally left off the public site.
